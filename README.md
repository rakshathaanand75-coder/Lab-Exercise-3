# UI-UX-Experiment3

## Aim:
To perform a heuristic evaluation and comparative analysis of the Amazon.in and Flipkart homepages, identify usability issues, and suggest improvements to enhance user experience.

## Algorithm:
Heuristic Evaluation of an Existing Website or App

Compare and analyze the UX of 2–3 competing apps/websites.

Develop and incorporate required changes in the analysed apps/websites.
